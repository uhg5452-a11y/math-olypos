# Math Olympiad Hub 🏆 (ศูนย์รวมการแข่งขันและฝึกซ้อมคณิตศาสตร์ภายในโรงเรียน)

เว็บแอปพลิเคชันสำหรับการแข่งขันและฝึกซ้อมคณิตศาสตร์ภายในโรงเรียน (Intramural School Competition) พัฒนาด้วย **React + Tailwind CSS** พร้อมสถาปัตยกรรมหลังบ้าน **Firebase & Node.js**

3. **ขอบเขตการแข่งขันภายในโรงเรียน (Intramural School Competition)**:
   - การแข่งขันจัดขึ้นเป็นรอบตามที่แอดมินกำหนด เช่น รอบคัดเลือกตัวแทนห้อง, รอบชิงชนะเลิศระดับโรงเรียน
   - ชิงถ้วยเกียรติยศผู้อำนวยการโรงเรียน, ทุนการศึกษาของโรงเรียน และเกียรติบัตรกลุ่มสาระคณิตศาสตร์
4. **ระบบรับชมการแข่งขันสด (Live Match Spectator Mode)**:
   - นักเรียนคนอื่นสามารถกด "👁️ เข้าชมการแข่งขันสด (Watch Live)" ดูการแข่งขันของคู่แข่งขันที่กำลังแข่งอยู่แบบเรียลไทม์
   - มีหน้าจอกระดานแข่งขันสด, ข้อมูลนักเรียนคู่แข่งขัน, จำนวนผู้ชมสด และห้องแชทส่งข้อความ/สติกเกอร์เชียร์สด (Live Cheer Chat)
5. **โหมดทดลองเล่น / ฝึกซ้อม 24 ชั่วโมง (6 มินิเกม)**:
   - 🔤 **เอแมท (A-Math)**: สมการอักษรไขว้ 7x7 พร้อมเบี้ยตัวเลข เครื่องหมาย และช่องคะแนนพิเศษ
   - 🔢 **ซูโดกุ (Sudoku)**: ปริศนาตัวเลข 9x9 เลือกระดับความยาก โหมดจดโน้ตดินสอ และขอ Hint
   - ♟️ **หมากฮอสไทย (Thai Checkers)**:
     * **ตัวหมากปกติ (เบี้ย)**: ห้ามเดินถอยหลัง และห้ามกินถอยหลัง เดินหน้าได้อย่างเดียว
     * **ตัวฮอส (King)**: เดินและกินยาวทางไกลตามแนวทแยงได้ (Long-range movement and capture)
   - ⚡ **คิดเลขเร็ว (Speed Math)**: ท้าประลองความเร็ว 30s/60s สะสม Streak Combo Multiplier
   - 🧮 **เกม 24 (Make 24)**: ผสมตัวเลข 4 ตัวให้ได้ 24 พร้อมระบบ AI Solver แนะนำเฉลย
   - 🧠 **จินตคณิต (Flash Anzan)**: ตัวเลขกะพริบกลางอากาศ 0.5s - 1.2s คำนวณในใจ
6. **ระบบจัดการหลังบ้าน (Admin Panel สำหรับ 2 แอดมินผู้สร้าง)**:
   - จัดการรอบแข่งขันภายในโรงเรียน (เพิ่ม, แก้ไข, สลับเปิด/ปิดรับสมัครทันที)
   - จัดการห้องแข่งขันและบันทึกผล แพ้/ชนะ/เสมอ
   - จัดการกระดานผู้นำ (Leaderboard), ปรับแต้มโบนัส, Export CSV

## 🚀 วิธีการติดตั้งและรันโปรเจกต์ (Installation & Running)

### 1. ติดตั้ง Dependencies:
```bash
npm install
```

### 2. รัน Frontend Development Server:
```bash
npm run dev
```
เข้าใช้งานผ่านเบราว์เซอร์ที่: `http://localhost:3000`

### 3. รัน Node.js Backend Server (ทางเลือก):
```bash
node server/index.js
```
API จะรันที่พอร์ต: `http://localhost:5000`
