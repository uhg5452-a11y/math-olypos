# Math Olympiad Hub 🏆 (ศูนย์รวมการแข่งขันและฝึกซ้อมคณิตศาสตร์)

เว็บแอปพลิเคชันสำหรับการแข่งขันและฝึกซ้อมคณิตศาสตร์โอลิมปิก พัฒนาด้วย **React + Tailwind CSS** พร้อมสถาปัตยกรรมหลังบ้าน **Firebase & Node.js**

---

## 🎨 ฟีเจอร์หลัก (Key Features)

1. **การตกแต่งและธีม (UI/UX Design)**:
   - โทนสีหลัก: Dark Blue (`#0B192C`), Navy (`#1E3E62`), Bright Blue (`#008DDA`) และ White (`#FFFFFF`)
   - Interactive Canvas Background: สัญลักษณ์คณิตศาสตร์ $\sum, \pi, \int, \sqrt{x}, \infty, e^{i\pi}+1=0$ ลอยละล่อง 3D Glow พร้อม Parallax ตามการเคลื่อนที่ของเมาส์
2. **ระบบยืนยันตัวตนและสิทธิ์ (Authentication & RBAC)**:
   - **นักเรียน**: ล็อกอินด้วย "รหัสประจำตัวนักเรียน" (Student ID) และ Password
   - **แอดมิน (จำกัด 2 บัญชี)**: ล็อกอินด้วย Email & Password เข้าสู่ Admin Dashboard พร้อมระบบ RBAC ป้องกันสิทธิ์ระดับสูง
3. **ระบบจัดการการแข่งขัน (Student Portal)**:
   - เปิด-ปิดรับสมัครตามรอบที่แอดมินกำหนด ไม่เปิดตลอดเวลา
   - ปฏิทินและไทม์ไลน์การแข่งขัน
   - ระบบแจ้งเตือนสด (Countdown Alert / Toast) ล่วงหน้า 15 นาทีก่อนเริ่มแข่ง
4. **โหมดทดลองเล่น / ฝึกซ้อม 24 ชั่วโมง (6 มินิเกม)**:
   - 🔤 **เอแมท (A-Math)**: สมการอักษรไขว้ 7x7 พร้อมเบี้ยตัวเลข เครื่องหมาย และช่องคะแนนพิเศษ
   - 🔢 **ซูโดกุ (Sudoku)**: ปริศนาตัวเลข 9x9 เลือกระดับความยาก โหมดจดโน้ตดินสอ และขอ Hint
   - ♟️ **หมากฮอสไทย (Thai Checkers)**: กติกาหมากฮอสไทยแท้ สู้กับบอทคอมพิวเตอร์ AI หรือเล่น 2 คน
   - ⚡ **คิดเลขเร็ว (Speed Math)**: ท้าประลองความเร็ว 30s/60s สะสม Streak Combo Multiplier
   - 🧮 **เกม 24 (Make 24)**: ผสมตัวเลข 4 ตัวให้ได้ 24 พร้อมระบบ AI Solver แนะนำเฉลย
   - 🧠 **จินตคณิต (Flash Anzan)**: ตัวเลขกะพริบกลางอากาศ 0.5s - 1.2s คำนวณในใจ
5. **ระบบจัดการหลังบ้าน (Admin Panel สำหรับแอดมิน 2 คน)**:
   - จัดการรอบแข่งขัน (เพิ่ม, แก้ไข, สลับเปิด/ปิดรับสมัครทันที)
   - จัดการห้องแข่งขันและบันทึกผล แพ้/ชนะ/เสมอ
   - จัดการกระดานผู้นำ (Leaderboard), ปรับแต้มโบนัส, Export CSV

## 🚀 วิธีการติดตั้งและรันโปรเจกต์ (Installation & Running)

### 1. ติดตั้ง Dependencies:
```bash
npm install
```

### 2. รัน Frontend Development Server:
```bash
npm run dev
```
เข้าใช้งานผ่านเบราว์เซอร์ที่: `http://localhost:3000`

### 3. รัน Node.js Backend Server (ทางเลือก):
```bash
node server/index.js
```
API จะรันที่พอร์ต: `http://localhost:5000`
