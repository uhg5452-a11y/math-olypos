# Math Olympiad Hub 🏆 (โรงเรียนบรรหารแจ่มใสวิทยา 3)

เว็บแอปพลิเคชันระบบการแข่งขันและฝึกซ้อมคณิตศาสตร์แบบเรียลไทม์ (Real-time Multiplayer & Arena System) สำหรับ **โรงเรียนบรรหารแจ่มใสวิทยา 3** พัฒนาด้วย **React + Tailwind CSS** พร้อมสถาปัตยกรรมหลังบ้าน **Socket.IO, WebSocket & Node.js/Firebase**

---

## ⚡ 1. ระบบการแข่งขันแบบเรียลไทม์ (Real-time Multiplayer Match System)
- รองรับการเชื่อมต่อพร้อมกันจาก 2 เครื่อง (Player 1 ฝ่ายฟ้า และ Player 2 ฝ่ายแดง)
- เมื่อผู้เล่นเดินหมาก, วางสมการ, หรือส่งคำตอบ ข้อมูลจะส่งข้ามเครื่องและอัปเดตกระดานทันที **แบบ Real-time โดยไม่ต้องกดรีเฟรชหน้าจอ** (ผ่าน Socket.IO / WebSocket / BroadcastChannel)
- มีระบบแสดงสถานะการเชื่อมต่อสด `⚡ เชื่อมต่อเรียลไทม์ (2 เครื่อง)` พร้อมรหัสห้องแข่งขัน (เช่น `M101`) สำหรับแชร์ให้อีกเครื่องเข้าห้องเดียวกัน

---

## 📺 2. หน้าจอแสดงผลกลาง (Central / Arena Projector Display)
- เมนู **"📺 จอแสดงผลกลาง (Arena)"** ออกแบบมาเฉพาะสำหรับเปิดขึ้นจอโปรเจกเตอร์ใหญ่ในหอประชุม หรือจอทีวีหน้าห้องแข่งขัน
- แสดงกระดานแข่งขันขนาดใหญ่ (High-Contrast Big Board) เห็นชัดจากระยะไกล
- ตัวนับเวลานับถอยหลังขนาดใหญ่ (Giant Match Clock) พร้อมสถานะผู้เล่นฝ่ายฟ้า vs ฝ่ายแดง
- แถบวิ่งแสดงข้อความเชียร์สด (Live Cheer Feed Ticker) และปุ่มขยายเต็มหน้าจอ (Fullscreen Mode)

---

## 👁️ 3. ระบบรับชมสดเรียลไทม์สำหรับผู้ชม (Live Spectator Mode)
- นักเรียนในโรงเรียนบรรหารแจ่มใสวิทยา 3 สามารถเปิดจากโทรศัพท์มือถือ แท็บเล็ต หรือโน้ตบุ๊ก แล้วกด **"👁️ เข้าชมสด"**
- หน้าจอผู้ชมจะซิงค์การเดินหมากและคะแนนแบบเรียลไทม์ตรงกับเครื่องของผู้เล่นทั้งสองคน
- มีห้องแชทส่งกำลังใจเชียร์สด (Live Cheer Chat) สามารถพิมพ์ส่งข้อความหรือกดปุ่มสติกเกอร์ด่วน (👏, 🔥, 💡, 🏆) ซึ่งจะเด้งไปแสดงที่หน้าจอแสดงผลกลางทันที

## ♟️ 5. กติกาเกมหมากฮอสไทยแท้แบบเรียลไทม์ (Thai Checkers Rules)
- **ตัวหมากปกติ (เบี้ย)**: เดินหน้าได้อย่างเดียว 1 ช่องทแยง **ห้ามเดินถอยหลัง และห้ามกินถอยหลัง**
- **ตัวฮอส (King)**: เมื่อเดินสุดกระดานจะเข้าฮอส (👑) สามารถ **เดินยาวทางไกล** ตามแนวทแยง 4 ทิศทาง และสามารถ **กินยาวทางไกล** ข้ามหมากฝ่ายตรงข้ามได้ทั้งหน้าและหลังแบบเรียลไทม์

## 🚀 วิธีการติดตั้งและรันโปรเจกต์ (Installation & Running)

### 1. ติดตั้ง Dependencies:
```bash
npm install
```

### 2. รัน Real-time Socket.IO Backend Server:
```bash
node server/index.js
```
*API และ Socket.IO Server จะเริ่มทำงานที่พอร์ต: `http://localhost:5000`*

### 3. รัน Frontend Development Server:
```bash
npm run dev
```
*เข้าใช้งานผ่านเบราว์เซอร์ที่: `http://localhost:3000`*
